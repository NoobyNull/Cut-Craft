# Choosing the icons

PowerWhittle's buttons and pictures are drawn **flat** to start with, and the flat icons are
always built in. Other looks come as **icon themes**: add-ons you install only if you want
one.

## Install an icon theme

1. Open **Gadgets ▸ Add-ons...**.
2. Press **Install** beside the icon theme you want, such as **3D Icons**.
3. When it's done, the window says to pick it in **Edit ▸ Options ▸ Icons**.

## Pick the icons

1. Open **Edit ▸ Options** and choose **Icons** on the left.
2. Pick **Flat (built in)** or one of the sets your themes bring. **3D Icons** brings two:
   **3D** (face-on) and **3D (angled)**.
3. Press **Apply**. The buttons change at once; nothing else in your job changes.

A theme doesn't have to draw everything. Any button or picture its set has no picture for
keeps its flat icon, so nothing is ever left blank. Measurement pictures beside settings
keep their flat versions, because their letters must match the settings exactly.

If you remove the theme you picked (**Gadgets ▸ Add-ons**, **Remove**), PowerWhittle goes
back to the flat icons the next time it starts, and the status bar says why.

## Official or not

An icon theme holds only pictures, so it can't run anything or change your files. The 3D
Icons theme is **official**: PowerWhittle signed it with its release key. A theme that isn't
signed still works, but it is marked **⚠ not official**, the same as any other
[add-on](help:addons).
