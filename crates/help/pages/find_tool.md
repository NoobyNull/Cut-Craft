# Find Tool

Can't remember where a tool lives? **Find Tool** opens any tool by typing part of its
name, whichever window layout you use and however the tool groups are folded.

![Find Tool with "poc" typed, listing the tools with that in their name](pictures/basics/find-tool.png)

1. Press **Ctrl+K** (or pick **Edit ▸ Find Tool…**). A small box opens at the top of the
   view, ready to type in.
2. Type part of the tool's name: `poc` finds Pocket Toolpath, `circ` finds Draw Circle
   and Circular Copy. The list under the box shrinks as you type.
3. Press **Enter** to open the first tool in the list, or click any tool in it.

The tool opens just as if you had pressed its button: its form on the Design or
Toolpaths page, ready to fill in.

- Only tools you can use right now are listed. A tool that needs something first is left
  out until it is there: Edit Text waits for a text to be picked, Zoom to Selection for a
  shape. Point at a greyed-out button to see what it is waiting for.
- **No tool has that in its name** means nothing matched: try a shorter part of the name,
  or another word for it.
- **Esc** closes Find Tool without opening anything.

Looking for how to do something rather than a tool's name? Use **Search help** in the
Help window: see [Finding help](help:finding_help).
