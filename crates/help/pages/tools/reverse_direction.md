**Reverse Direction** makes the vector you right-click run the other way: its start and end trade
places. A toolpath following it cuts the other way. It is on node editing's right-click menu.

## Steps

![The steps, one after another](pictures/reverse_direction/tour.gif)

1. Select an open vector and press **Node Edit**: the cut runs from its start to its end.

   ![Step 1](pictures/reverse_direction/step-1.png)

2. Right-click it and choose **Reverse Direction**. Its start and end trade places, so it is cut the other way.

   ![Step 2](pictures/reverse_direction/step-2.png)

## Good to know

- Pick where a closed vector starts with [Make Start Point](help:make_start_point).
