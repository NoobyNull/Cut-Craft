**Move Up** and **Move Down** over the Layers list move the current layer one place up or down.
The order is only how layers are listed and drawn: it never changes how they are cut.

## Steps

![The steps, one after another](pictures/reorder_layer/tour.gif)

1. Open **Layers** and click the layer to move, so it is the active one.

   ![Step 1](pictures/reorder_layer/step-1.png)

2. Press **Move Up** or **Move Down** over the list. The order is only how the layers are listed and drawn.

   ![Step 2](pictures/reorder_layer/step-2.png)

3. The layer is one place lower in the list now (Move Up takes it back up).

   ![Step 3](pictures/reorder_layer/step-3.png)

## Good to know

- Click a layer's name first to make it the current one.
