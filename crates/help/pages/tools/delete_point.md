**Delete Point** takes out the node you right-click. The spans either side become one straight
line. It is on node editing's right-click menu.

## Steps

![The steps, one after another](pictures/delete_point/tour.gif)

1. Select the shape and press **Node Edit**, then right-click the node to take out.

   ![Step 1](pictures/delete_point/step-1.png)

2. Choose **Delete Point**. The node goes, and a straight line joins the nodes either side.

   ![Step 2](pictures/delete_point/step-2.png)

## Good to know

- Pick several nodes with a box in node editing and press Delete to take them all out.
- To add a node, use [Insert Point](help:insert_point).
