## Steps

![The steps, one after another](pictures/drilling_toolpath/tour.gif)

1. Draw a small circle where each hole goes, then select them all. Each circle's middle is where the bit goes down.

   ![Step 1](pictures/drilling_toolpath/step-1.png)

2. On the Toolpaths page, press **Drilling** (under Holes).

   ![Step 2](pictures/drilling_toolpath/step-2.png)

3. Set the **Cut Depth** (D): how deep each hole goes.

   ![Step 3](pictures/drilling_toolpath/step-3.png)

4. Turn on **Peck** for deep holes: the bit lifts out now and then to clear the chips, so it does not jam or burn.

   ![Step 4](pictures/drilling_toolpath/step-4.png)

5. Press **Calculate** to make the toolpath. Each circle becomes one straight plunge.

   ![Step 5](pictures/drilling_toolpath/step-5.png)

For holes bigger than the bit, cut them with a [Profile](help:profile_toolpath) set to Inside instead.
