**Cut Vector** opens a vector at the node you right-click: a closed shape becomes open there,
and an open one is cut in two. It is on node editing's right-click menu.

## Steps

![The steps, one after another](pictures/cut_vector/tour.gif)

1. Select the vector, press **Node Edit**, then right-click the node where it should open.

   ![Step 1](pictures/cut_vector/step-1.png)

2. Choose **Cut Vector**. The shape is open at that node now: drag one end away and the gap shows.

   ![Step 2](pictures/cut_vector/step-2.png)

## Good to know

- Insert a node first with [Insert Point](help:insert_point) if you need to cut where there is
  none.
- Join the ends again with [Join / Close Vectors](help:join_close_vectors).
