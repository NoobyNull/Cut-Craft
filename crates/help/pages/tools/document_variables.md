## Steps

![The steps, one after another](pictures/document_variables/tour.gif)

1. Variables are named numbers kept with the job, such as {thickness}, to use in any number box.

   ![Step 1](pictures/document_variables/step-1.png)

2. On the Design page, under **Create**, press **Document Variables**.

   ![Step 2](pictures/document_variables/step-2.png)

3. Add a name and a value. Type {name} in a number box to use it; change it here and every box using it follows.

   ![Step 3](pictures/document_variables/step-3.png)
