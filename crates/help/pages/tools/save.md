## Steps

![The steps, one after another](pictures/save/tour.gif)

1. Save the job: the drawing, the 3D model and the toolpaths, all in one file. Save often.

   ![Step 1](pictures/save/step-1.png)

2. Press **Save** (under File Operations). The first time, name the file; after that it saves over it.

   ![Step 2](pictures/save/step-2.png)
