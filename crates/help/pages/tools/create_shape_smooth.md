## Steps

![The steps, one after another](pictures/create_shape_smooth/tour.gif)

1. A smooth shape rises with soft, pillowy sides. Select the closed shape.

   ![Step 1](pictures/create_shape_smooth/step-1.png)

2. On the Design page, under **Model**, press **Create Shape: Smooth**.

   ![Step 2](pictures/create_shape_smooth/step-2.png)

3. Set the height and how soft the sides are, then press **Create**.

   ![Step 3](pictures/create_shape_smooth/step-3.png)

4. The circle rises into a soft, rounded cushion.

   ![Step 4](pictures/create_shape_smooth/step-4.png)
