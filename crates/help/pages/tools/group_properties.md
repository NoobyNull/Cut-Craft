**Group Properties** changes a component group's name and how it combines with what is under
it. Right-click the group's name in **Components** ▸ **Properties** (or **Rename**).

## Steps

![The steps, one after another](pictures/group_properties/tour.gif)

1. Open **Components**, right-click a group's name and choose **Properties**.

   ![Step 1](pictures/group_properties/step-1.png)

2. Rename the group, and pick how it combines with what is under it. Every component in it takes that mode.

   ![Step 2](pictures/group_properties/step-2.png)

## Settings

- **Name**: what the group is called in the Components list.
- **Combine Mode**: Add, Subtract, Merge, Low or Multiply, set on every component in the group.
  See [Component Properties](help:component_properties).
