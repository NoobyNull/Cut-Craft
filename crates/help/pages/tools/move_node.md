**Node Position...** moves the node you right-click to a place you type. It is on
node editing's right-click menu, for when dragging isn't exact enough.

## Steps

![The steps, one after another](pictures/move_node/tour.gif)

1. Select the shape and press **Node Edit**, then right-click the node to place exactly.

   ![Step 1](pictures/move_node/step-1.png)

2. Choose **Node Position...** and type where the node goes.

   ![Step 2](pictures/move_node/step-2.png)

3. Press **Apply**. The node moves there and the spans either side follow it.

   ![Step 3](pictures/move_node/step-3.png)

## Settings

- **From**: the node being moved (filled in from where you right-clicked).
- **To**: where it goes, X and Y.
