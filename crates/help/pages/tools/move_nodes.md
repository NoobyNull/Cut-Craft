In node editing, drag a box round several nodes to pick them, then drag one: they all move by the
same amount, keeping their places to each other.

## Steps

![The steps, one after another](pictures/move_nodes/tour.gif)

1. In **Node Edit**, drag a box round the nodes to move: they are picked together.

   ![Step 1](pictures/move_nodes/step-1.png)

2. Drag one of them: they all move by the same amount, keeping their places to each other.

   ![Step 2](pictures/move_nodes/step-2.png)

## Good to know

- Shift-click a node to add it to the picked ones.
- See [Node Edit](help:node_edit).
