**Select All Vectors** (Ctrl+A, or Edit ▸ Selection) selects every vector you can change.

## Steps

![The steps, one after another](pictures/select_all_vectors/tour.gif)

1. Press **Ctrl+A** (or **Edit ▸ Selection ▸ Select All Vectors**) to select every vector you can change.

   ![Step 1](pictures/select_all_vectors/step-1.png)

2. Vectors on hidden or locked layers are left out. **Unselect All** (or Esc) clears the selection.

   ![Step 2](pictures/select_all_vectors/step-2.png)

## Good to know

- Vectors on hidden or locked layers are left out.
- For only some of them, see [Vector Selector](help:vector_selector) and
  [Select Layer Vectors](help:select_layer_vectors).
