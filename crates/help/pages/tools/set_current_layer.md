The current layer is the one new vectors, text and imports go on. Click a layer's name in
**Layers** (or right-click ▸ **Activate**) to make it current.

## Steps

![The steps, one after another](pictures/set_current_layer/tour.gif)

1. Open **Layers** at the top of the Design page: the current layer is highlighted.

   ![Step 1](pictures/set_current_layer/step-1.png)

2. Click another layer's name (or right-click ▸ **Activate**). New vectors, text and imports go on it now.

   ![Step 2](pictures/set_current_layer/step-2.png)

## Good to know

- A shape remade from others (Weld, Trim, Join and the like) stays on the layer the originals
  were on.
- The layer box at the top of the view shows the current layer and changes it too.
