**Space Vertically** spreads the selected objects so the gaps between them up the job are even.
It is in **Edit ▸ Align Selected Objects**.

## Steps

![The steps, one after another](pictures/space_vertically/tour.gif)

1. Select three or more shapes, clicking them in the order you want them from bottom to top.

   ![Step 1](pictures/space_vertically/step-1.png)

2. Choose **Edit ▸ Align Selected Objects ▸ Bottom To Top**. The gaps between them are now even up the job.

   ![Step 2](pictures/space_vertically/step-2.png)

## The choices

- **Space Vertically** on the right-click menu keeps them in the order they sit: the top and
  bottom ones stay where they are.
- **Bottom To Top**: the first one you picked goes at the bottom, so the ends can move too.
- **Top To Bottom**: the first one you picked goes at the top, so the ends can move too.
- **Vertically Inside Last Vector**: spreads them inside the last vector picked, which stays put.

See [Space Horizontally](help:space_horizontally) for spacing across.
