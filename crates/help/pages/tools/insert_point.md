**Insert Point** adds a new node on the span you right-click, splitting it there. Drag the new
node to reshape that side. It is on node editing's right-click menu.

## Steps

![The steps, one after another](pictures/insert_point/tour.gif)

1. Select the shape and press **Node Edit**, then right-click on a span where a new node should go.

   ![Step 1](pictures/insert_point/step-1.png)

2. Choose **Insert Point**. A new node splits the span there; drag it to reshape the side.

   ![Step 2](pictures/insert_point/step-2.png)

## Good to know

- Take a node out with [Delete Point](help:delete_point).
- See [Node Edit](help:node_edit) for everything node editing does.
