To make one model taller or lower, double-click it in the 3D view, then double-click it again for its height buttons. See [3D View](help:view_3d), Changing a model's height.

## Steps

![The steps, one after another](pictures/scale_model_z_height/tour.gif)

1. Scale Model Z Height squashes or stretches the whole model to a new height.

   ![Step 1](pictures/scale_model_z_height/step-1.png)

2. On the Design page, under **Model**, press **Scale Model Z Height**.

   ![Step 2](pictures/scale_model_z_height/step-2.png)

3. Type the new height and press **Apply**.

   ![Step 3](pictures/scale_model_z_height/step-3.png)

4. The model is squashed or stretched to exactly the height you typed.

   ![Step 4](pictures/scale_model_z_height/step-4.png)
