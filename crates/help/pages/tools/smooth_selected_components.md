## Steps

![The steps, one after another](pictures/smooth_selected_components/tour.gif)

1. Smooth softens a 3D part's shape. Select the part in the Components list.

   ![Step 1](pictures/smooth_selected_components/step-1.png)

2. On the Design page, under **Model**, press **Smooth Selected Components**.

   ![Step 2](pictures/smooth_selected_components/step-2.png)

3. Set the number of passes and press **Apply**: more passes, softer shape.

   ![Step 3](pictures/smooth_selected_components/step-3.png)

4. The part's surface is softer, with the small steps smoothed out.

   ![Step 4](pictures/smooth_selected_components/step-4.png)
