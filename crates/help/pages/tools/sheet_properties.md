**Rename** on a sheet's right-click menu changes the sheet's name in the Sheets list. Its size and
setup are set in [Job Setup](help:job_setup) while it is active.

## Steps

![The steps, one after another](pictures/sheet_properties/tour.gif)

1. Open **Sheets**, right-click a sheet and choose **Rename**.

   ![Step 1](pictures/sheet_properties/step-1.png)

2. Type a name that says what is cut from it, such as Back panel.

   ![Step 2](pictures/sheet_properties/step-2.png)

3. Press **Apply**. The sheet is listed by its new name; its size is set in **Job Setup**.

   ![Step 3](pictures/sheet_properties/step-3.png)

## Good to know

- Only the active sheet is drawn, so a sheet has no Show or Hide.
