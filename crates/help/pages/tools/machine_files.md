## Steps

1. Tell PowerWhittle where your machine's files are: in **Machine ▸ Machine Configuration**,
   under **G-code Files**, give the folder its card or stick shows up as on this computer,
   a shared folder, or the machine's web address.
2. Press **Machine Files** (in **Save for the Machine** on the Toolpaths bar, on the Output
   tab of the Toolpaths page in the Classic layout, or in the Machine menu).
3. A window lists the files and folders there. Click a folder's name to open it; **⬆ Up**,
   or a name in the path along the top, goes back.
4. **Upload Files…** copies files from this computer into the folder open there. **Rename**,
   **Delete** and **New Folder** tidy it up, and **Refresh** reads it again. Delete asks once
   more before it removes anything.

## Good to know

- Saving with **Send to Machine** in [Save Toolpaths](help:save_toolpaths) puts the file
  there for you; Machine Files is for looking at what is there and tidying it.
- A file the machine is cutting now can be replaced from here: you are asked first, so
  choose No while it is running.
- PowerWhittle does not drive the machine: it only moves files to where the machine reads
  them.
